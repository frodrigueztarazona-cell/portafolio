# Carpeta de Evidencias (Capturas)

Por favor, sube a esta carpeta las capturas de pantalla tomadas durante la ejecución de los comandos Git en tu terminal local.

**Comandos a documentar:**
- `git init` y `git status`
- `git add .` y `git commit`
- `git log --oneline` (Demostrando los 6 commits)
- `git branch`, `git switch` (o `checkout`) y `git merge`
- `git remote -v` y `git push`
