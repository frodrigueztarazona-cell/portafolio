Un portafolio web personal moderno, interactivo y responsivo, desarrollado como proyecto de evaluación académica para destacar habilidades, experiencia y proyectos de programación.

## 🛠️ Tecnologías Utilizadas
Este proyecto ha sido construido utilizando tecnologías modernas de desarrollo web frontend:
- **HTML5:** Estructura semántica.
- **CSS3:** Estilos personalizados, animaciones y scroll suave.
- **JavaScript (Vanilla):** Lógica de interacción (menú responsivo, validación de formulario, navegación fluida).
- **Tailwind CSS:** Framework de diseño utilitario (vía CDN para facilitar el despliegue sin build process).
- **Git & GitHub:** Control de versiones y alojamiento de repositorio.
- **GitHub Pages:** Despliegue web.

## 📸 Guía de Capturas de Pantalla Requeridas (`/capturas`)
Como parte de la rúbrica de evaluación, se debe evidenciar el correcto uso del control de versiones. Las capturas deben guardarse en la carpeta `capturas/` mostrando la ejecución de los siguientes comandos en la terminal:

1. **Inicialización y Estado:** `git init` y `git status`
2. **Staging y Commits:** `git add .` y `git commit`
3. **Historial Completo:** `git log --oneline` (Debe demostrar los 6 commits estructurados).
4. **Manejo de Ramas:** `git branch`, `git checkout`/`git switch` y `git merge` (Evidenciando el trabajo en `feature/proyectos`).
5. **Repositorio Remoto:** `git remote -v` y `git push` (Si aplica para la subida a GitHub).

## 🤖 Uso de Inteligencia Artificial
- **Herramienta utilizada:** Google Antigravity / Gemini 3.1 Pro.
- **Prompt utilizado:** Se empleó un prompt de instrucción maestra ("PROMPT DE INSTRUCCIÓN MAESTRA: CREACIÓN DE PORTAFOLIO WEB Y ESTRUCTURA DE EVALUACIÓN TÉCNICA") detallando el contexto del estudiante, la estructura de archivos requerida, las especificaciones técnicas (HTML, Tailwind CSS, JS) y el flujo exacto de control de versiones.
- **Cómo se aplicó la asistencia de IA:** La IA se utilizó como un mentor y desarrollador senior ("Pair Programming") para acelerar la maquetación inicial con buenas prácticas, aplicar un diseño UI/UX moderno (Glassmorphism, gradientes, animaciones) mediante Tailwind CSS, estructurar un código semántico, implementar la lógica de interacción en JavaScript, y simular/automatizar el flujo de control de versiones con Git siguiendo la rúbrica de evaluación (6 commits secuenciales y uso de ramas). Esto permitió garantizar un código limpio, profesional y listo para despliegue en GitHub Pages.
